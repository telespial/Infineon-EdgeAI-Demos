# Infineon EdgeAI Demos

This repository contains EdgeAI demonstrations organized as independent project directories. Current entries are [drone-hunter](./drone-hunter), [HAL 2026 PSE84](./hal-2026-pse84), [insulin-pump](./insulin-pump), and [smart-pong](./smart-pong). Read each project README and status or validation files before building; hardware and toolchain details are project-specific.

The insulin-pump project is a research/demo project and must not be interpreted as clinical approval or medical readiness.
