# Infineon EdgeAI Demos

This repository contains EdgeAI demonstrations organized as independent project directories. Current entries are [drone-hunter](./drone-hunter), [HAL 2026 PSE84](./hal-2026-pse84), [insulin-pump](./insulin-pump), and [smart-pong](./smart-pong). Read each project README and status or validation files before building; hardware and toolchain details are project-specific.

The insulin-pump project is a research/demo project and must not be interpreted as clinical approval or medical readiness.

See [LICENSE](./LICENSE) for license terms.

## How the examples relate

The projects cover a PSoC Edge E84 drone-hunter simulation with deterministic fallback, a HAL workspace, an insulin-pump research platform, and Smart Pong comparing human, fixed-algorithm, and adaptive control. Work-in-progress and research boundaries remain in the child documentation. The [EIL specification](https://github.com/telespial/Embedded-Intelligence-Layer-Specs) provides context for bounded runtime intelligence; the [EmbeddedX index](https://github.com/telespial/EmbeddedX-Specs) links the wider specification family.
